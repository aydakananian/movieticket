# سامانه هوشمند خرید بلیط سینما (مووی تیکت) 🎬

## معرفی کوتاه ایده و هدف محصول
«مووی تیکت» یک وب‌سایت سریع، سبک و کاربرپسند برای خرید آنلاین بلیط سینما است. هدف اصلی این پروژه حل مشکل صف‌های طولانی گیشه، عدم امکان انتخاب دقیق صندلی به صورت بصری، و یکپارچه‌سازی تخفیف‌ها است.

## قابلیت‌ها و امکانات اصلی (MVP)
۱. **مدیریت حساب کاربری و احراز هویت:** ثبت‌نام و ورود با شماره موبایل و کد تایید (OTP).
۲. **جستجو و مشاهده جزئیات فیلم و سانس‌ها:** فیلتر فیلم‌ها بر اساس ژانر، سینما و تاریخ به همراه نمایش تریلر و اطلاعات کارگردان.
۳. **انتخاب صندلی بصری و رزرو آنلاین:** نمایش نقشه صندلی‌های سالن و رزرو موقت ۵ دقیقه‌ای صندلی‌های مد نظر.
۴. **پرداخت و صدور بلیط دیجیتال:** اتصال به درگاه پرداخت تستی.
